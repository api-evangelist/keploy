Open-source, AI-native testing platform that captures real production API traffic with eBPF and replays it in CI as deterministic tests, auto-generated mocks, and production-like sandboxes with zero code changes. Publishes a first-party OpenAPI 3.0.3 for its Cloud REST API, a hosted MCP server with a 112-tool catalog, llms.txt, and a Kubernetes Proxy REST API for in-cluster recording and replay.

**Areas:** Testing & QA · API Testing · Integration/Regression Testing · Unit Test Generation · Contract Testing · CI/CD · Developer Tools · AI / Agent Tooling · eBPF / Observability · Test Data & Mocking · Testing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Keploy: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
